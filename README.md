# 🎮 Tic Tac Toe Game

A classic two-player **Tic Tac Toe** game built using **React**, **Vite**, and **Tailwind CSS**.

Play as **X** or **O** and enjoy a smooth, clean UI with instant game feedback. This project is a great example of a simple yet fully functional web game created with modern front-end tools.



---

## 🚀 Features

This game includes everything you need for a quick match:

* ✔️ **Two-player Tic Tac Toe:** Enjoy classic head-to-head gameplay.
* ✔️ **Highlights the winner:** Visually indicates the winning line (horizontal, vertical, or diagonal).
* ✔️ **Turn indicator:** Clearly shows the **Next Player: X / O**.
* ✔️ **Reset button:** Instantly clear the board and start a new game.
* ✔️ **Minimal and responsive UI:** Looks great and works well on any device.
* ✔️ **Modern stack:** Built with cutting-edge tools (**Vite + React + Tailwind**).

## ⚙️ Installation and Setup

Follow these steps to get a copy of the project up and running on your local machine.

### Prerequisites

You need to have **Node.js** installed on your system.

### Steps

1.  **Clone the repository:**
    ```bash
    git clone [YOUR_REPO_URL]
    cd tic-tac-toe-react
    ```

2.  **Install dependencies:**
    ```bash
    npm install
    # or
    yarn install
    ```

3.  **Start the development server:**
    ```bash
    npm run dev
    # or
    yarn dev
    ```

4.  The application should now be running at `http://localhost:5173` (or the port specified by Vite).
